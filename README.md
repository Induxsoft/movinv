# Inventario (Gestión de inventarios)
El paquete Inventario (Gestión de inventarios) de V12 es el módulo que permite la administración de existencias mediante movimientos de inventario, además de ofrecer herramientas para conteo físico y control de máximos, mínimos y puntos de reorden. Su propósito es garantizar un manejo eficiente de los recursos materiales, evitando faltantes o excesos y asegurando la trazabilidad de cada movimiento.
